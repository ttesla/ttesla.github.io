Well, it has been a while since I posted anything here. Meanwhile:

- **I ported an ActionScript/Flash game to Nintendo Switch!** It's a precise platformer adventure game. It is very timing-sensitive, so the port had to work exactly like the original or you wouldn't be able to pass some of the levels. That super precise timing requirement created so many problems when porting the platformer part of the game. There was also the adventure side of the game, which has several Flash-based animations and sequences. I recreated those animations in Unity with video files (mp4). It sounds quite hacky but it worked like a charm. I had to write some tools to manage these animations (video files), though. There are many details to talk about, maybe I will make a video or write a post about it later.

  > If you like platformers with a thrilling story and leaderboards, buy & play: [A Night at the Races](https://www.nintendo.com/us/store/products/a-night-at-the-races-switch/)
